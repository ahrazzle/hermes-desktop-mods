# Protean Desktop Mods — Reapply Runbook (post-Hermes-update)

Purpose: after a Hermes desktop app update replaces the renderer bundle, reapply
the three Protean desktop mods:

1. Group-chat caps override (rounds/messages/continuations -> 9999, members stays 6)
2. Group-room slash commands (sendToGroupChat intercepts /cmd)
3. group-model-sync desktop plugin (per-member model selector + agent-wide sync)

> Coming from a pre-Protean install? The launchd label, watchdog script and log
> filenames changed. See `MIGRATION.md` before reinstalling.

## What is on git (this repo) vs. local-only

## Prerequisites

- Hermes desktop app updated and launched once (so the new bundle exists).
- gh authenticated as ahrazzle.

## Step 1 — Restore tooling (only if ~/.hermes/scripts was lost)

    mkdir -p ~/.hermes/scripts
    cp patch-groupchat-caps.py patch-groupchat-slash.py protean-caps-watchdog.sh \
       groupchat-mods-manifest.txt ~/.hermes/scripts/
    chmod +x ~/.hermes/scripts/protean-caps-watchdog.sh
    cp com.protean.caps-watchdog.plist ~/Library/LaunchAgents/
    launchctl unload ~/Library/LaunchAgents/com.protean.caps-watchdog.plist 2>/dev/null
    launchctl load   ~/Library/LaunchAgents/com.protean.caps-watchdog.plist

## Step 2 — Reapply caps + slash (idempotent)

    bash ~/.hermes/scripts/protean-caps-watchdog.sh

Expected: rc=0, log lines "PATCHED ..." or "ALREADY PATCHED", re-signed.
Exit rc=3 on either patcher means the new bundle's minified shape changed and
the anchor must be re-derived from the refreshed source tree before patching
(see groupchat-mods-manifest.txt "POST-UPDATE RE-DERIVATION LOG" for the
procedure). DO NOT ship without resolving rc=3 — caps/slash are unverified.

Verify markers on the new bundle (~/.hermes/hermes-agent/apps/desktop/release/
mac-arm64/Hermes.app/Contents/Resources/app.asar.unpacked/dist/assets/index-*.js):

    grep -c __GSPATCH <bundle>            # expect 1
    grep -c '`settled`;try{for(' <bundle> # expect 1 (literal is rename-agnostic; the 9999 form sits one token later)
    codesign --verify --deep --strict Hermes.app

## Step 3 — Restore group-model-sync plugin

Plugin root is PROFILE-AWARE: the active desktop profile (from
~/Library/Application Support/Hermes/active-profile.json) determines which
~/.hermes/profiles/<active>/desktop-plugins/ dir is loaded.

    git clone https://github.com/ahrazzle/hermes-group-model-sync.git
    cp hermes-group-model-sync/desktop/plugin.js \
       ~/.hermes/profiles/<active>/desktop-plugins/group-model-sync/plugin.js

Also mirror to ~/.hermes/desktop-plugins/group-model-sync/ and any other
profile dirs so a profile switch doesn't lose it. Verify registration via the
Cmd+K palette (PLUGINS header) after restarting the desktop app.

## Step 4 — Verify end-to-end

- Caps: run a long multi-agent room round; confirm it does not cut off at 3/10/2.
- Slash: in a group room type `/model @agent` (or any exec/plugin command);
  confirm an entry posts into the room thread.
- Model sync: open the plugin pane in a Bot Mode room; confirm member models
  are listed and selectable.
